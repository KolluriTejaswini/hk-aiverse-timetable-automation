# HK AI VERSE Round 2 — Task 1

## College Master Timetable Automation

This project demonstrates a Python-based prototype for automating college timetable preparation.

### Features
- Excel-based synthetic input data
- Automated timetable generation
- Faculty, room, and section clash validation
- Section-wise and faculty-wise timetable outputs
- Test cases and validation reports
- Documentation of the existing process, proposed workflow, and limitations

### Run the project

Install the dependencies:

```bash
pip install -r task1/requirements.txt
```

Run the demo:

```bash
python task1/src/run_demo.py
```

Run the tests:

```bash
python task1/src/run_tests.py
```

### Important limitation

The current prototype uses synthetic data and has not yet been validated against the college's complete real timetable data. Time-saving figures are estimates, not confirmed measurements.

See `task1/README.md` for further details.
