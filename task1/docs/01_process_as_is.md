# 1. How the master timetable is prepared today (as-is)

Labels: **[O]** observed in files, **[R]** reported by the student (to be confirmed with the coordinators), **[A]** assumption. Evidence IDs refer to `evidence/evidence_log.md`.

## Steps, owners and handoffs

| # | Step | Who | Hands off to | Approval / check |
|---|---|---|---|---|
| 1 | Decide semester subjects for every year and the faculty for each [R E08] | HoD | Timetable coordinators | HoD decision |
| 2 | Sections are formed at registration, with seats per section [R E08] | Registration / dept. office | Coordinators | none recorded |
| 3 | Allot classrooms from section seats and student numbers [R E08] | 2 coordinating faculty | same | none recorded |
| 4 | Place labs for all years and sections using the available labs [R E09] | Coordinators | | rule |
| 5 | Place industry-faculty classes on their fixed days [R E09] | Coordinators | | rule |
| 6 | Keep S1 free for HoDs (rounds) [R E09] | Coordinators | | rule |
| 7 | Fill theory periods, produce master + odd-semester timetable in Excel [O E01, E02] | Coordinators | | |
| 8 | Derive individual faculty timetables [O E03] | Coordinators | Faculty | |
| 9 | Check clashes by eye; if clashes, revise and repeat 7-9 [R E08] | Coordinators | HoD | HoD sign-off (assumed) [A] |
| 10 | Keep each faculty at 16-18 h/week [R E09] | Coordinators | | rule |

## Exceptions seen or reported
- Clash found after drafting -> redo (loop 7 -> 9) [R E08].
- Industry faculty availability limits when classes can be placed [R E09].
- Lab availability limits the placement of lab blocks (lab grids show few free pairs) [O E04].
- Formatting inconsistencies in the sheets (repeated day "M,M, Th", stray spaces in room codes) show that errors can enter at data entry [O E06].

## Where the pain is
Same decisions are re-typed in three places (master, section grids, individual timetables) [O E01-E03], and checking is visual. This is an inference from the file structure, not a measured fact [A].
